# 💻 Projetos em destaque

## ✅ TaskHub

Aplicação Full Stack para gerenciamento de tarefas, projetos e etiquetas.

**Stack:** Next.js, React, TypeScript, ASP.NET Core, Entity Framework Core e SQLite.

Principais recursos:

* arquitetura organizada em Controller, Service e Repository;
* API REST;
* DTOs;
* filtros, busca, ordenação e paginação;
* projetos e etiquetas;
* histórico de alterações;
* exclusão lógica e restauração;
* validação de dados;
* logs com Serilog;
* health check;
* testes automatizados com xUnit.

🔗 [Ver projeto](https://github.com/gustavobarcelos18/TaskHub)

## 📊 DataFlow

Aplicação para importação e validação de planilhas Excel antes da transformação dos dados em JSON.

**Stack:** Next.js, TypeScript, ASP.NET Core, ClosedXML e xUnit.

Principais recursos:

* upload de arquivos `.xlsx`;
* validação da estrutura da planilha;
* validação individual dos registros;
* regras de negócio no back-end;
* geração controlada de JSON;
* cálculo SHA-256 dos arquivos;
* cache local com IndexedDB;
* testes automatizados.

🔗 [Ver projeto](https://github.com/gustavobarcelos18/DataFlow)
