### About me

I'm Gustavo, a **Full Stack (.NET + React)** developer from **Leopoldina, Minas Gerais, Brazil** ✝️.

Making a feature work is not enough for me. I want to understand **why** a solution exists, what it costs in architecture, and how it behaves under real use.

### How I work

- **Understand the why before the how.** A technical decision without a reason becomes debt.

- **End to end.** From the database and the API to the interface and the deployment.
